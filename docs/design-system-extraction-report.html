적용 원칙

[확인된 규칙]현재 사용자 규정과 공용 구현에서 추출한 실행 기준입니다. 아래 원칙 모두가 현재 구현에 완전히 반영돼 있다는 뜻은 아닙니다.

  1. 본문은 Pretendard, 페이지와 주요 섹션 제목은 Paperozi로 역할을 분리한다.
  2. 한글 본문 16px, 한글 가시 텍스트 최소 13px과 작은 UI 최대 weight 500을 지킨다.
  3. 공용 --ui-* 표면과 글자 토큰으로 라이트 및 다크를 대응한다.
  4. 팀 강조색과 기존 캠페인 팔레트는 해당 맥락에서 사용한다.
  5. 전체보기는 SectionHeading, 셀렉트는 FilterDropdown을 재사용한다.
  6. 밀도는 간격과 정보 구조로 조절하고 글자를 줄여 해결하지 않는다.
  7. 데이터 목록은 모바일 정보 배치로 바꾸고 미디어 카드는 캐러셀 흐름을 보존한다.
  8. 로딩은 해당 페이지의 실제 구조를 따른다. 필수 상태 안내와 조작은 보존한다.
  9. 불필요한 부제와 장식 구분자를 추가하지 않고 경계는 필요한 그룹에 사용한다.
