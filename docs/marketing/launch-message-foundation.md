# MINION 출시 메시지 기준

작성일: 2026-09-01
적용 범위: Google Play 스토어, 웹 앱 유도 문구, SNS 프로필·게시물, 크리에이터 제휴, 출시 콘텐츠

## 1. 이번 단계에서 확정한 결정

MINION을 `새로운 롤 커뮤니티`나 `LCK 정보를 모두 모은 앱`으로 소개하지 않는다.

초기 사용자는 커뮤니티로 이동하기 위해 앱을 설치하지 않는다. 응원팀 경기와 소식을 놓치지 않고 경기 전후에 직접 참여하기 위해 설치하며, 팬톡은 그 경험을 이어주는 공간으로 소개한다.

### 대표 브랜드 약속

> 최애팀의 모든 순간을 놓치지 않게

### 대표 제품 설명

> 알림을 설정해 경기 시작과 실시간 주요 장면, 팀·선수의 새 콘텐츠를 받아보고 승부예측·팬평점 확인과 팬톡으로 함께하는 LCK 팬앱.

### 대표 CTA

> 최애팀 설정하고 시작하기

이 세 문장을 임의로 바꾸지 않고 모든 출시 소재의 기준으로 사용한다.

## 2. 첫 타깃

### 핵심 사용자

- 응원하는 LCK 팀이 있다.
- 매주 한 경기 이상 보거나 경기 일정·결과를 확인한다.
- 경기 시작, 세트 평가, 팀·선수 콘텐츠를 놓친 경험이 있다.
- 경기 전 예상과 경기 후 선수 평가에 의견을 남기고 싶다.

### 핵심 문제가 아닌 것

- 일반 랭크 게임 공략을 찾는 모든 LoL 이용자를 대상으로 하지 않는다.
- 기존 대형 커뮤니티를 대체하는 것을 첫 목표로 삼지 않는다.
- 뉴스 기사 수나 게시글 수로 기존 서비스와 경쟁하지 않는다.

## 3. 메시지 구조

| 역할 | 메시지 | 제품 근거 |
| --- | --- | --- |
| 감정적 약속 | 최애팀의 모든 순간을 놓치지 않게 | 최애팀·팔로우 팀 중심 경험 |
| 첫 설치 이유 | 경기와 팀 소식을 필요한 순간에 받기 | 사용자가 켠 경기 시작·세트 평가·실시간 주요 장면·팀 콘텐츠 알림 |
| 첫 참여 이유 | 보기 전에 예측하고 끝난 뒤 팬들의 평가 확인하기 | LP 승부예측·선수 팬평점·평점 공유 이미지 |
| 재방문 이유 | 다음 경기와 새 소식이 다시 찾아오기 | 일정·푸시·딥링크·팀별 알림 |
| 관계 형성 | 같은 팀 팬들과 경기 이야기를 이어가기 | 허브 팬톡·팀 팬톡·댓글·반응 |

메시지 노출 순서는 `알림과 경기 효용 → 승부예측·팬평점 → 팬톡`으로 유지한다.

## 4. 길이별 소개 문구

### 한 문장

> 최애팀 경기 알림부터 승부예측, 팬평점과 팬톡까지 함께하는 LCK 팬앱.

### 10초 소개

> MINION은 알림을 설정해 최애팀 경기와 새 소식을 받아보고, 경기 전에는 예측하고 경기 후에는 선수 팬평점과 팬톡을 확인하는 LCK 팬앱입니다.

### 30초 소개

> LCK 경기 일정과 팀 소식이 여러 곳에 흩어져 있어 중요한 순간을 놓치는 팬을 위한 앱입니다. 알림을 설정해 최애팀의 경기 시작과 실시간 주요 장면, 팀·선수 콘텐츠를 받아보고 경기 전 승부예측, 경기 후 선수 팬평점 확인과 팬톡까지 한 흐름에서 즐길 수 있습니다.

## 5. Google Play 문구 초안

### 앱 이름

`MINION`을 유지한다. `공식`, `대표`, `최대`처럼 제휴나 우위를 암시하는 수식어를 붙이지 않는다.

### 짧은 설명

> LCK 경기·팀 소식 알림부터 승부예측, 팬평점과 팬톡까지 한곳에서.

### 상세 설명 첫 문단

> 최애팀의 경기를 놓치고 뒤늦게 결과부터 본 적 있나요? MINION에서 LCK 일정과 경기 정보를 확인하고, 원하는 알림을 켜 응원팀의 경기 시작과 주요 소식을 받아보세요. 경기 전에는 승부예측에 참여하고, 경기 후에는 선수 팬평점을 확인하며 팬톡으로 이야기를 이어갈 수 있습니다.

### 상세 설명 기능 순서

1. 최애팀 경기·세트 평가·팀 콘텐츠 알림
2. LCK 일정과 경기 결과 스포방지
3. 경기 전 LP 승부예측
4. 세트별 데이터와 경기 후 선수 팬평점 확인
5. 팀·선수 뉴스, 소셜 게시물과 영상
6. LCK 전체 팬톡과 팀별 팬톡

기능을 추가하더라도 이 순서를 첫 출시 기간에는 유지한다.

## 7. 채널별 프로필 문구

### Instagram·YouTube

> 오늘 LCK 경기에서 볼 장면과 숫자를 정리합니다. 경기 전 예측부터 경기 후 팬평점 확인까지, MINION.

### 크리에이터·제휴 소개

> MINION은 원하는 LCK 경기와 최애팀 소식 알림을 설정하고, 경기 전 예측과 경기 후 팬평점·팬톡을 즐기는 독립 팬 서비스입니다.

## 8. 상황별 CTA

`앱 다운로드`를 모든 화면에 반복하지 않는다. 사용자가 보고 있는 맥락의 다음 행동을 제안한다.

| 노출 위치 | CTA |
| --- | --- |
| 일정 | 다음 경기 알림 받기 |
| 예정 경기 | 승부예측 참여하기 |
| 종료 경기 | 팬들의 선수 평점 확인하기 |
| 팀 페이지 | 최애팀 설정하고 알림 고르기 |
| 뉴스·영상 | 팀의 새 콘텐츠 알림 받기 |
| 평점 공유 이미지 | 팬들의 전체 평점 보기 |
| 팬톡 읽기 | 한 줄 의견 남기기 |
| 일반 랜딩 | 최애팀 설정하고 시작하기 |

## 9. 사용하지 않을 표현

- `새로운 롤 커뮤니티로 오세요`, `기존 커뮤니티를 대체합니다`
- 근거 없는 `국내 1위`, `대표`, `최대`, `완벽한`, `유일한`
- 공식 제휴로 오인될 수 있는 `공식 LCK 앱`, `Riot 공식`
- `베팅`, `배당`, `돈 버는 예측`, `수익`, `환전`
- 결과를 보장하는 `AI가 승자를 맞혀드립니다`
- 콘텐츠 양만 강조하는 `모든 롤 정보`, `모든 뉴스를 가장 빠르게`
- 빈 팬톡을 숨기기 위한 `수많은 팬이 활동 중` 같은 검증되지 않은 표현

승부예측은 현금 가치가 없는 서비스 내 LP로 참여하는 팬 활동으로만 설명한다.

## 10. 콘텐츠 문체

- 팬과 같은 높이에서 말하되 특정 팀·선수 조롱을 유도하지 않는다.
- 제목은 질문이나 관전 포인트처럼 바로 반응할 수 있게 쓴다.
- 데이터는 출처와 집계 시점을 함께 표시한다.
- 앱 기능보다 사용자가 얻게 되는 결과를 먼저 말한다.
- `다운로드하세요`보다 `다음 경기 알림 받기`, `팬평점 확인하기`처럼 구체적으로 말한다.

### 좋은 예

- `오늘 1세트에서 먼저 봐야 할 라인은?`
- `경기 시작 10분 전, 최애팀 알림 받기`
- `팬들이 뽑은 3세트 POM은 누구였을까?`

### 피할 예

- `MINION에는 다양한 기능이 있습니다`
- `최고의 LCK 커뮤니티가 출시됐습니다`
- `설치하고 많은 이용 부탁드립니다`

## 11. 신뢰 표기

모든 스토어·랜딩·제휴 소재는 MINION이 Riot Games, LCK 또는 참가 팀이 운영·보증하는 공식 서비스로 보이지 않게 한다. 현재 제품의 비공식 팬 서비스 고지를 유지하고, 유료 마케팅 전 Riot Developer Portal의 제품 등록·수익화 상태를 별도로 확인한다.

## 12. 출시 문구 기능 게이트

공개 문구는 구현이 아니라 검증된 사용자 동작을 기준으로 한다.

- 현재 모바일 팬평점 화면은 조회만 가능하다. 평점 작성 UI·제출·로그인 후 원래 화면 복귀까지 실제 기기에서 검증되기 전에는 `평점을 남긴다`, `평가에 참여한다`를 스토어와 광고에 사용하지 않는다.
- 최애팀 선택만으로 모든 푸시가 자동 활성화되는 것으로 표현하지 않는다. 항상 `알림을 설정하면`, `원하는 알림을 켜면`처럼 사용자의 선택을 드러낸다.
- 준비 중이거나 플레이스홀더인 화면은 스토어 스크린샷에 넣지 않는다.
- 기능이 구현되면 이 게이트를 해제하고 `팬평점 확인` 문구를 `팬평점 남기기`로 일괄 승격한다.
