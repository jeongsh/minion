## 1. 바로 붙여 넣을 등록정보

### 앱 이름

```text
MINION
```

- 길이: 6자
- Google Play 제한: 최대 30자. 한국어 도움말의 상충 표기를 고려해 한글 이름은 15자 이내를 안전 기준으로 사용한다.
- `공식`, `대표`, `1위`, `최대` 같은 오인·과장 표현을 붙이지 않는다.

### 짧은 설명

```text
LCK 경기·팀 소식 알림부터 승부예측, 팬평점과 팬톡까지 한곳에서.
```

- 길이: 38자
- Google Play 제한: 최대 80자
- 알림, 경기 참여, 팬 커뮤니티를 한 문장에 담되 팬평점 작성은 약속하지 않는다.

### 상세 설명

```text
최애팀의 경기를 놓치고 뒤늦게 결과부터 본 적 있나요?

MINION은 LCK 일정과 경기 정보, 팀·선수 소식, 팬들의 반응을 한곳에서 확인하는 독립 팬 앱입니다. 원하는 알림을 직접 설정해 응원팀의 중요한 순간을 받아보고, 경기 전에는 승부예측에 참여하고 경기 후에는 세트 데이터와 팬평점을 확인해 보세요.

■ 원하는 팀과 순간만 알림으로
- 경기 시작과 세트 평가 시작
- 라이브 경기의 킬과 주요 오브젝트
- 팀·선수의 새 Instagram 게시물과 영상
- 소속 선수의 솔로 랭크 시작
- 내 글의 새 댓글과 내 댓글의 답글

알림 종류는 팀별로 직접 선택할 수 있으며, 기기 푸시 허용 여부도 따로 관리할 수 있습니다.

■ LCK 일정을 빠르고 편하게
- 날짜별 경기 일정과 현재 상태 확인
- 진행 중인 경기와 종료된 경기 정보
- 결과를 원할 때까지 가려주는 스포방지

■ 경기 전에는 승부예측
- 응원하는 팀을 선택하고 팬들의 선택 비율 확인
- 현금으로 환전되지 않는 앱 활동 포인트 LP로 참여
- 내 예측 기록과 LP를 한 계정으로 관리

■ 경기 후에는 데이터와 팬평점
- 세트별 스코어와 선수 지표
- 밴픽과 주요 타임라인
- 팬들이 남긴 선수 평점과 한 줄 리뷰 확인

■ 최애팀 소식을 한곳에서
- 팀과 선수의 뉴스, 소셜 게시물, 영상
- 선수단과 예정 경기
- LCK 전체 팬톡과 팀별 팬톡

MINION은 Riot Games, LCK 또는 참가 팀이 운영하거나 보증하는 공식 서비스가 아닙니다. League of Legends와 Riot Games 관련 명칭, 로고 및 게임 자산의 권리는 각 권리자에게 있습니다.
```

- Google Play 제한: 최대 4,000자
- 기능 이름을 반복해 검색어처럼 나열하지 않는다.
- 팬평점 작성 기능이 모바일에 구현·검증되기 전까지 `평점을 남겨보세요`로 바꾸지 않는다.

## 2. 휴대전화 스크린샷 6장

### 공통 제작 규격

- 최종 캔버스: `1080×1920px`, 세로 9:16, 24비트 PNG, 알파 없음
- 실제 앱 화면을 이미지의 80% 이상 사용한다.
- 상단 카피 영역은 20% 이내로 제한하고 UI를 가리지 않는다.
- 모든 장면은 동일한 Android 기기, 동일한 라이트 또는 다크 테마로 촬영한다. 현재 자산과 브랜드 대비를 고려해 다크 테마를 사용한다.
- 상태 표시줄의 시간·배터리, 테스트 계정 닉네임, 알림의 개인정보가 장마다 모순되지 않게 한다.
- `설치`, `다운로드`, 가격, 할인, 순위, 수상, 근거 없는 최상급 문구를 넣지 않는다.
- 실제 출시 빌드에 없는 화면, 합성된 기능, 가짜 이용자 반응을 넣지 않는다.

### 1장 — 알림

- 헤드라인: `최애팀의 중요한 순간을 알림으로`
- 보조 문구: `경기·라이브·팀 콘텐츠를 원하는 만큼`
- 실제 화면: `/me`의 알림 섹션
- 촬영 상태: 로그인한 전용 촬영 계정, 팔로우 팀 1개, 해당 팀 카드 펼침, 경기·라이브 경기·Instagram·동영상 선택지가 보이게 한다.
- 주의: 모든 알림이 자동으로 켜진 것처럼 만들지 않는다. 사용자가 종류를 선택할 수 있다는 화면을 보여준다.

### 2장 — 일정과 스포방지

- 헤드라인: `오늘 경기를 한눈에`
- 보조 문구: `일정은 빠르게, 결과는 스포 없이`
- 실제 화면: `/schedule`
- 촬영 상태: 종료 경기와 예정 경기가 함께 있는 주, 필터에서 스포방지 ON, 종료 경기 결과가 가려진 상태
- 주의: 스포방지 ON 상태가 실제 UI 안에서 확인되어야 한다. 별도 배지만 합성해 기능을 암시하지 않는다.

### 3장 — 승부예측

- 헤드라인: `보기 전에는 승부예측`
- 보조 문구: `팬들의 선택과 함께 즐기는 경기`
- 실제 화면: `/predictions`
- 촬영 상태: 로그인, 아직 닫히지 않은 경기, 양 팀 선택 비율과 보유 LP가 보이도록 한다. 가능하면 팀 선택 후 실제 승부예측 시트를 연다.
- 주의: `베팅`, `배당`, `수익`, `환전` 표현을 쓰지 않는다. LP는 현금 가치가 없는 앱 활동 포인트다.

### 4장 — 세트 데이터

- 헤드라인: `경기 후에는 데이터로 복기`
- 보조 문구: `선수 지표와 주요 타임라인을 한눈에`
- 실제 화면: `/matches/{matchId}`의 데이터 탭
- 촬영 상태: 상세 데이터가 충분한 종료 경기와 세트 선택, 스코어·선수 지표 또는 타임라인이 명확히 보이게 한다.
- 주의: 현재 팬평점 작성 화면은 출시 기능 게이트에 걸려 있으므로 평점 작성 CTA를 스크린샷 핵심으로 사용하지 않는다.

### 5장 — 최애팀 팬페이지

- 헤드라인: `내 팀 소식을 한곳에서`
- 보조 문구: `뉴스·소셜·영상·선수단까지`
- 실제 화면: `/fan/{team}`
- 촬영 상태: 팀 헤더, 최신 소셜 또는 영상, 선수단으로 이어지는 구조가 한 화면에서 이해되게 한다.
- 주의: 특정 팀을 공식 파트너처럼 보이게 하지 않는다. 팀 로고·사진·게시물의 스토어 홍보 사용 권한을 출시 전 확인한다.

### 6장 — 팬톡

- 헤드라인: `경기 이야기는 팬들과 계속`
- 보조 문구: `LCK 전체와 팀별 팬톡`
- 실제 화면: `/community` 또는 `/fan/{team}/community`
- 촬영 상태: 운영팀·에디터·실제 창립 팬으로 작성 관계가 투명한 게시글 3~5개, 서로 다른 말머리와 실제 댓글·반응이 보이게 한다.
- 주의: 가짜 계정, 가짜 댓글, 조작한 조회·반응 수를 사용하지 않는다. 개인정보와 테스트용 문구가 노출되지 않게 한다.

## 3. 피처 그래픽

- 규격: `1024×500px`, JPEG 또는 24비트 PNG, 알파 없음
- 현재 `mobile/store-assets/feature-graphic-1024x500.png`의 크기는 맞지만 메시지가 `LCK, ALL IN ONE`으로 되어 있어 출시 포지셔닝과 맞지 않는다.
- 기존 앱 아이콘·캐릭터 방향은 유지하되 아래 문구로 교체한다.

```text
최애팀의 모든 순간을
놓치지 않게

경기 알림 · 승부예측 · 팬톡
```

- 로고와 핵심 문구는 중앙 안전 영역에 둔다. 이미지 가장자리에는 중요한 요소를 배치하지 않는다.
- LCK·팀 로고를 장식 요소로 추가하지 않는다.

현재 휴대전화 스크린샷은 긴 변이 짧은 변의 2배를 넘어 Google Play 게시 규격에 맞지 않는다. 단순 리사이즈로 찌그러뜨리지 말고, 실제 화면을 다시 캡처하거나 9:16 캔버스에서 비율을 유지해 크롭한다.

파일 픽셀 형식도 함께 검사했다. 기존 휴대전화 캡처 4장은 24비트 RGB지만 비율을 다시 맞춰야 하고, 앱 아이콘과 피처 그래픽은 위 표의 형식으로 재내보내야 한다. 기존 파일은 원본 보존 대상으로 두고 최종 산출물을 별도 파일명으로 만든다.

## 5. 촬영 전 데이터 체크리스트

- [ ] 실제 출시 빌드와 동일한 버전 사용
- [ ] 다크 테마와 한국어 로케일 통일
- [ ] 촬영 전용 계정 사용, 개인 이메일·실명·기기 알림 제거
- [ ] 팔로우 팀과 알림 선택 상태 준비
- [ ] 예정 경기, 종료 경기, 데이터가 충분한 세트 준비
- [ ] 진행 가능한 승부예측 경기 준비
- [ ] 팀 팬페이지의 뉴스·소셜·영상 데이터 확인
- [ ] 투명한 작성자 관계가 표시된 팬톡 시드 콘텐츠 준비
- [ ] 로딩·오류·빈 상태·플레이스홀더가 없는지 확인
- [ ] 외부 기사 이미지, 팀·선수 사진, 로고의 홍보 사용 권리 확인
- [ ] 최종 6장 모두 1080×1920, 알파 없음 확인

## 6. Play Console 입력 전 확인

- 지원 이메일은 필수다. 사용자에게 응답 가능한 운영 메일을 등록한다.
- 웹사이트는 권장 항목이다. 현재 서비스 소개·개인정보처리방침·지원 페이지로 연결한다.
- 개인정보처리방침 URL은 공개 상태, 로그인 불필요, 모바일 열람 가능 여부를 확인한다.
- 앱 이름·설명·스크린샷이 현재 출시 빌드의 실제 기능과 일치하는지 다시 대조한다.
- Riot 제품 등록·수익화 상태와 제3자 로고·미디어 사용 권리를 별도로 확인한다.
- Play Console의 실제 문자 카운터와 이미지 검사 결과를 최종 기준으로 삼는다.
