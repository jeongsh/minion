**MINION | 소재 발굴형 SNS + 직접 쓰는 게시판 — 2주 실행안**

**요약: SNS는 이미 반응이 나온 소재를 골라 편집한다. 사이트에서는 같은 롤 이슈를 보고 직접 글을 쓴다. 새 드립·상황극·댓글 대본은 만들지 않는다.**

| 구분 | 할 일 | 첫 2주 분량 |
| --- | --- | --- |
| 쇼츠·릴스 | 커뮤니티에서 발견한 소재의 영상화 3편 + 관련 미니언 기록·기능 1편 | 주 4편, 총 8편. 같은 완성본을 두 플랫폼에 게시 |
| X | 영상에서 쓴 소재·사용 가능한 이미지·핵심 내용 재활용 | 영상 게시일에 함께 게시. 별도 아이디어 회의 없음 |
| 미니언 게시판 | 경기·선수 소식·밴픽·기록을 보고 운영자가 자기 말로 작성 | 하루 짧은 글 1~2개부터. 경기 중에는 실제 반응대로 |
| 외부 커뮤니티 | 소재·이슈를 읽는 용도 | 광고 게시글·홍보 댓글·위장 홍보 없음 |

두 사람 합계 하루 3시간, 광고비 0원 기준. 분량은 시험 목표다. 외부 게시·연락은 아직 실행하지 않았다.

**1. 쇼츠 소재는 이렇게 고른다 — 하루 20분까지만**

1. 평소 보는 펨코 롤 인기글·디시 개념글 등에서 최근 후보 **3개만** 저장한다.
2. `원문 링크 / 게시일 / 웃기거나 관심을 끄는 부분 / 사용 가능한 자료`를 한 줄씩 적는다.
3. 아래 세 항목에 맞는 것 하나를 고른다. 없으면 보류하고 준비해둔 후보를 사용한다.

| 고를 기준 | 거를 것 |
| --- | --- |
| 실제 반응이 붙어 있고, 두 사람이 봐도 소개할 만하다 | 추천 수만 높고 내용을 이해하기 어려운 글 |
| 배경 설명 한 문장이면 내용을 따라갈 수 있다 | 긴 팬덤 싸움·여러 과거 사건을 알아야 하는 글 |
| 30~45초에 핵심을 전달할 수 있다 | 설명을 줄이면 원래 뜻이나 재미가 달라지는 글 |

인기글이면 영상도 잘된다는 보장은 없다. **매번 소재를 발명하는 부담을 줄이는 선별 기준**이다.

**2. 편집은 한 가지 틀로 반복한다**

| 구간 | 넣을 것 |
| --- | --- |
| 첫 3초 | 제목과 필요한 배경 한 문장 |
| 중간 | 사용 가능한 원문·이미지를 읽는 순서대로 배치. 목소리 또는 일반 TTS와 자막 |
| 끝부분 | 원래 글의 핵심·결말까지 전달. 필요한 사실 설명만 보충 |
| 마지막 2초 | 미니언 이름·주소. 관련 자료가 있을 때만 해당 화면 안내 |

Clipchamp 등 익숙한 편집기에서 **세로 9:16 프로젝트 하나**를 만들고 복제한다. 매번 효과·배경음·자막 디자인을 바꾸지 않는다. 완성 MP4를 쇼츠·릴스에 각각 올리고, X에는 같은 소재를 짧게 재편집한다. 플랫폼마다 새 농담을 만들지 않는다.

**자료 사용은 구분한다.** 말씀하신 무단 캡처·낭독형은 제작 형식의 참고 대상이다. 공식 채널에서 사용할 원문은 재사용 조건이나 허락 범위를 확인한다. 출처 표시만으로 복제·낭독 권리가 생기는 것은 아니며, 글 속 타인의 짤·클립·댓글도 별도 확인 대상이다. [한국저작권위원회 안내](https://www.copyright.or.kr/customer-center/faq/list.do?categorycode1=02&searchkeyword=)

확인을 매번 반복하는 부담은 **사용 범위를 합의한 작성자·자료 목록**으로 줄인다. 쇼츠·릴스·X 중 허용된 곳에만 사용한다. 사용 가능한 후보가 없으면 그날은 경기 사실·기록을 확인해 직접 설명하거나 게시를 쉰다. 짧은 해설을 붙였다는 이유만으로 권리 문제가 해결되지는 않는다.

참고로 단순 낭독·최소 수정 재사용은 YouTube 수익화 제한 대상이 될 수 있다. 이는 업로드 가능 여부·저작권과 별도 기준이며, 미니언 사이트의 AdSense 심사와도 구분한다. [YouTube 정책](https://support.google.com/youtube/answer/1311392?hl=ko)

**3. 미니언 글은 ‘같은 이슈, 직접 쓴 내용’으로 만든다**

새 주제를 발명할 필요는 없다. 오늘 롤판에서 이미 이야기하는 주제 중 두 사람이 할 말이 있는 것을 고른다. 원글의 창작 드립·사연을 표현만 바꿔 옮기지는 않는다.

| 발견한 소재 | 사이트에서 실제로 할 작업 |
| --- | --- |
| 특정 선수 기록이 화제 | 해당 경기 기록을 열어 확인. 필요한 숫자와 자기 의견을 짧게 작성 |
| 밴픽·플레이 선택 논쟁 | 해당 밴픽이나 장면을 확인하고 본인이 보는 쟁점 하나 작성 |
| 팀·선수 새 소식 | 원출처 확인, 링크와 자기 반응 작성 |
| 남이 쓴 글 자체가 웃긴 소재 | SNS용 후보로만 둬도 됨. 억지로 사이트 글까지 만들지 않음 |

글마다 질문·드립·교훈을 붙이지 않는다. 두 분이 평소 쓰는 말투를 쓴다. 댓글도 대본 없이 실제 글을 읽고 답한다. AI를 쓰면 **두 사람이 고른 소재의 정리·축약·자막 작업**에 쓰고, 팬인 척 반응을 만들어내는 데 쓰지 않는다.

초기 활동은 허브 전체 피드에 집중한다. 경기 중 장면별 새 글과 경기 후 드립을 허용하는 운영을 한다. 운영자는 신분을 밝히고 참여한다. 새 이용자의 글이 올라오면 준비한 원글보다 그 글에 반응하는 시간을 먼저 쓴다.

**4. 조회수를 미니언 방문으로 연결한다**

| 콘텐츠 | 연결할 곳 |
| --- | --- |
| 가벼운 유머·사연 소개 | 미니언 이름을 알리는 용도. 모든 영상에 사이트 방문을 강요하지 않음 |
| 실제 경기·선수 기록 이야기 | 영상에 나온 경기·기록 화면 |
| 사이트에서 직접 쓴 관련 글 | 그 글과 이어지는 대화 |

프로필 링크는 웹의 공지 **‘영상별 관련 자료’**로 연결한다. `영상 제목 / 미니언 관련 페이지 / 외부 원출처`를 구분해 적고 새 영상 때 갱신한다. 펨코 원문을 미니언 원글처럼 표시하지 않는다.

유튜브 쇼츠 설명·댓글 URL은 클릭되지 않으므로, 필요한 영상에서는 **프로필 링크**를 안내한다. [YouTube 링크 안내](https://support.google.com/youtube/answer/13748639)

초기 외부 소재로 채널을 운영하다가 미니언에 소개할 만한 실제 이용자 글이 생기면, 작성자 동의를 받고 영상 후보에 포함한다. 외부 글 소개만 계속하면 SNS만 성장할 수 있으므로 방문과 실제 참여를 따로 확인한다.

첫날에는 편집 틀·계정 프로필·관련 자료 공지를 준비한다. 1주차 4편, 2주차 4편을 시험한다. 사용 허락 대기·첫 편 틀 제작은 별도 여유가 필요하므로 편수를 억지로 맞추지 않는다.

기록은 네 개만: **편당 작업시간 / 영상 조회·시청 지속 / 미니언 링크 방문 / 방문 후 글·댓글·재방문.** 사람의 이동을 확인할 수 없으면 미확인으로 둔다.

| 2주 뒤 결과 | 다음 행동 |
| --- | --- |
| 만드는 데 여전히 몇 시간씩 든다 | 배경 설명 긴 소재를 빼고 편집 요소 축소 |
| 영상 반응은 있는데 사이트 방문이 없다 | 관련 기록·페이지가 있는 소재의 비중을 늘림 |
| 방문은 있지만 글·댓글이 없다 | 실제 글쓰기 경로와 도착 콘텐츠 점검. 읽기 재방문은 별도 확인 |

Android는 비공개 테스트 상태를 표시하고 웹부터 이용하게 한다. AdSense 준비는 병행한다. 기존 커뮤니티 광고와 매일 새 유머 창작을 선행 조건으로 두지 않는다.
