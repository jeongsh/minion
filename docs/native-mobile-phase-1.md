# 네이티브 모바일 1단계 — 공통 셸 요약

상태: 구현 완료·잠금, iOS/Android 실제 기기 회귀 QA 필요.

2026-08-22 통합 변경: 홈 최초 로딩은 완성된 홈 화면의 매치·뉴스·커뮤니티 구조를 그대로 반영한 skeleton을 사용한다. 캐시 데이터가 있으면 skeleton으로 되돌리지 않고 기존 화면을 유지한 채 갱신한다.

유지 영역:

- 실제 `logo.svg`와 정확한 웹 폰트를 사용하는 헤더
- 스크롤 방향에 따른 헤더 노출/숨김
- 허브·팬 로컬 내비게이션
- 홈·매치·팬·팀·뉴스 독바
- 최애팀 없음 → 선택 모달, 팀 선택 → 이동만 수행
- 최애팀 설정 후 팬 독바 팀 로고 표시
- 라이트·다크 테마, safe area, 바텀시트와 토스트

이 영역은 잠금 상태이므로 일반 화면 작업에서 임의 수정하지 않는다. 현재 수치와 검증 규칙은 [`docs/native-mobile/README.md`](./native-mobile/README.md)에 있다.
