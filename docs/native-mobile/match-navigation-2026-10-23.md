# 매치 상세 모바일 탐색

- 웹 `app/matches/[matchId]/page.tsx`, `match-set-select.tsx`, 공용 `SegmentedControl`과 `FilterDropdown`을 기준으로 앱 탐색을 변경했다.
- 주요 탭이 세트 셀렉트 너비를 제외한 공간을 채우며 간격은 8px이다. 트랙과 셀렉트는 같은 배경색이고 높이는 40px이다. 목록은 셀렉트와 같은 너비다.
- 세트 및 평가 탭에서만 세트 셀렉트를 표시한다. 별도 세트 선택 줄은 제거하고 주요 탭과 셀렉트 전체가 상단에 고정된다. 기존 `MinionScreen`의 스크롤 및 헤더 API를 사용하며 잠금 파일은 수정하지 않았다.
- 공개 API, 세트 정렬과 초기 세트 판정, 조회 훅과 인증 계약은 유지했다. `app/api/mobile/v1/matches/[matchId]/route.ts`의 요청 `tab` 및 `set`에 따른 응답을 그대로 사용한다.
- 웹 320, 390, 768, 1440px에서 넘침 없음과 세트 전환을 확인했다. Expo Web 390×844에서 세트 선택과 스크롤 고정을 확인했다. 캡처는 로컬 `tmp/match-tabs`에 있으며 커밋과 빌드 업로드에서 제외한다.
- 앱 타입 검사 및 린트는 오류 없이 통과했다. 기존 린트 경고 2개는 남아 있다. 키보드 계약 테스트 4개를 통과했다. 기존 매치 API 테스트 5개는 브리핑 모듈의 mock 누락으로 실패했다.
- iPhone 및 Android 실기기와 전체 화면 1px 비교는 미실행이다. `OWNER-A.md`는 현재 체크아웃에 없어 `README.md`와 웹 소스를 실행 기준으로 사용했다.
- Expo Web의 라이트 및 다크 캡처를 확인했다. 주요 탭 네 개의 실제 너비는 각각 63.25px이며 높이는 34px이다. 테마 전환은 스크롤 전 표시된 헤더에서 확인했다.
- 사용자의 후속 요청으로 iOS 빌드와 TestFlight 배포 모두 중단했다. 빌드 명령 중단 전 원격 buildNumber 7 예약과 소스 업로드까지 진행됐으나 EAS의 최근 빌드 목록에 새 작업은 생성되지 않았다. 가장 최근 작업은 기존 빌드 6이다. Android 빌드 및 TestFlight 제출은 실행하지 않았다.
