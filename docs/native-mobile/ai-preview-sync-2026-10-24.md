# AI 프리뷰 모바일 동기화

## 변경 범위

- 웹 원본은 `app/matches/[matchId]/match-preview.tsx`, `match-preview-charts.tsx`, 공용 레이더와 파워랭킹 차트다. 앱의 이전 팀 프로필 화면을 현재 웹의 게이지, 팀 성향, 라인 격차, 드래곤 시점, 진영 승률, 챔피언 맵, 리그 비교, 관전 포인트와 적중률로 맞췄다.
- 모바일 웹의 라인 격차에서 선수명은 640px 미만에서 숨기고 수치는 축소하거나 말줄임하지 않는다.
- 모바일 v1의 기존 필드를 유지하며 선택 필드 `preview.briefing.charts`를 추가했다. 웹의 집계 함수, 저장 브리핑 자료, 드래곤 조회와 적중률 조회를 재사용한다. 스키마 변경은 없다. 비율 공개에 필요한 표본 기준은 플랫폼 독립 contracts 모듈로 공유한다.
- 앱 카드에 일괄 적용했던 `flex: 1`을 제거했다. 모바일 세로 목록은 내용 높이를 사용하고, 768px 이상에서 가로로 나란한 차트만 남은 너비와 높이를 공유한다. 제목과 본문이 서로 겹치거나 카드 밖으로 밀려나지 않게 했다.
- 현재 웹 원본의 모바일 팀명 16px/900, 팀 로고 40px, 리그 배지 12px/500, 파워랭킹 13px/500과 각각의 줄 높이를 반영했다. 차트 제목 18px/700, 메타 13px/500, 값 14px/500, 본문 16px/400 또는 700과 주요 수치의 굵기를 대조했다.
- 챔피언 맵은 웹에서도 오른쪽 끝의 좌표 제한 때문에 이름과 원이 겹쳤다. 웹과 앱이 같은 순수 배치 함수를 사용하며, 실제 차트 폭에 맞는 간격을 확보하고 각 행을 오른쪽부터 보정한다. 세 행과 픽 비중 순서를 유지한다. 이름은 한 줄로 표시한다.
- 프리뷰를 직접 여는 로딩 상태는 해당 화면의 골격을 사용한다. 잠금 파일과 폰트/로고 자산은 수정하지 않았다.

## 검증

- TSW vs LYON 경기 `ae13030e-e7f5-4fc6-880d-6dda5a98b6a5`를 390, 768, 1440px 라이트/다크의 웹과 Expo Web에서 비교했다. 프리뷰 API의 동일 응답을 앱에 전달해 상태를 고정했다.
- 표본이 없는 RED vs NAVI 경기 `f52c7cff-151d-415b-bb35-1438ce9cb83e`도 390px 라이트/다크에서 비교했다. 총 16개 화면에서 문서 가로 넘침과 JavaScript 런타임 오류는 없었다.
- 390px에서 TSW vs LYON의 프리뷰 카드 10개와 빈 표본 경기의 표시 카드 9개 모두 웹과 앱의 높이가 일치했다. 제목 뒤에 본문이 배치되고 모든 본문 하단이 카드 안에 있음을 측정했다. 동일하게 대응하는 텍스트의 크기와 굵기도 대조했다.
- 챔피언 맵의 실제 8개 항목을 차트 폭 254, 324, 616, 1158px에서 검사했다. 같은 행의 항목 사이에 이름 너비 72px보다 큰 간격을 확보하고 좌표 범위를 유지했다.
- 웹/앱 타입 검사, 앱 린트, 변경 웹 파일 ESLint, strict 타이포그래피 검사와 `git diff --check`를 통과했다. 앱 린트의 기존 경고 2개는 유지한다. 시각 집계와 적중률 관련 기존 검사 6개도 통과했다.
- 캡처, DOM 치수, 폰트 정보와 결과는 `.tmp/ai-preview-sync/recheck/`에 있다. 768px 이상에서는 웹의 사이드 레일이 차지하는 폭이 앱과 달라 전체 화면의 x 좌표와 너비가 같다고 주장하지 않는다.
- iPhone/Android 실기기와 네이티브 1px 전체 화면 비교는 미실행이다. Expo Web 검증을 실기기 검증으로 간주하지 않는다.

## 빌드 및 배포

사용자가 빌드 보류를 지시했다. 이번 작업에서 iOS/Android 빌드, TestFlight 제출과 서버 배포는 실행하지 않았다. 새 앱 차트를 실제 배포하려면 선택 필드를 제공하는 서버 변경도 함께 반영해야 한다.

## 1px 재점검

앞선 카드 높이와 글꼴 크기/굵기 비교는 내부 요소의 1px 일치를 증명하지 못했다. 사용자 재지적에 따라 다음 범위로 다시 측정했다.

- 390×844와 430×844 라이트/다크에서 AI 프리뷰 영역 시작점을 기준으로 팀 요약과 차트 카드 11개의 상대 x/y, 너비와 높이를 비교했다. 비교 대상 44개 카드의 위치와 크기는 일치했다.
- HTML 텍스트 노드 단위 대신 공백을 제외한 문자마다 Range 좌표를 비교했다. 대응 텍스트 3,288자의 x/y, 너비와 높이를 비교했으며, 430px 리그 비교 수치에서 마지막으로 발견한 오류를 수정하고 해당 카드의 라이트/다크를 별도 재확인했다. 최종 확인된 대응 글자의 차이는 1px 이내다.
- SVG 캔버스, 로고/챔피언 이미지, 가로 막대와 드래곤 점의 시각 외곽 232개를 비교했다. 드래곤 점의 웹 2px 외부 링과 앱 2px 내부 테두리는 실제 시각 외곽으로 환산했다. 최대 차이는 0.03125px다.
- 앱 섹션 제목의 줄 높이를 웹의 1.35배에 해당하는 27px로 맞춰 아래 카드로 누적되던 1px 차이를 제거했다. 진영 승률, 리그 수치, 적중률과 관전 포인트 번호에 빠졌던 tabular 숫자 설정을 보완했다. SVG 숫자에는 지원되는 `fontFeatureSettings`를 사용한다.
- 웹 드래곤 시간축의 끝 라벨이 `15`와 `분` 두 줄로 갈라지는 문제는 `whitespace-nowrap`로 수정했다. 앱의 한 줄 라벨과 동일하게 표시한다.
- 렌더링 중 생성 데이터가 변경되는 차이를 피하려고 실제 경기 응답을 고정하고 웹에서 읽은 동일 한줄평과 관전 포인트 상태로 비교했다. 화면 캡처, 겹침 비교 이미지와 문자/도형 좌표는 `.tmp/ai-preview-sync/pixel/`에 있다.
- 웹/앱 타입 검사, 앱 린트(기존 경고 2개), 변경 웹 파일 ESLint, strict 타이포그래피 검사와 `git diff --check`를 통과했다.

위 측정은 Chromium의 웹/Expo Web 비교다. iPhone 실기기에서의 렌더링과 화면 전체의 네이티브 1px 일치까지 통과한 것으로 보고하지 않는다. 빌드 및 배포 보류는 유지한다.
