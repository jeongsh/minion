# 팀 로고 로딩 개선

2026-10-27 사용자 요청: iOS 매치 등에서 팀 로고 이미지가 늦게 표시되는 현상을 개선한다.

## 통합 변경 범위

- 잠금 영역인 팀 로고의 공용 렌더러 `mobile/components/data/team-logo.tsx`에서 SVG 다운로드 경로만 교체한다. 자산, URL 선택, 다크 모드, 크기, 배경과 SVG 렌더링 엔진은 유지한다.
- 웹 근거는 `components/ui/team-logo.tsx`다. 웹과 동일한 원본 URL, plain 크기와 72% 비율을 유지한다. 웹은 브라우저 이미지 캐시를 사용하지만 기존 네이티브 SvgUri는 마운트마다 fetch를 시작한다.
- 네이티브 SVG에 URL별 메모리 캐시, 기기 저장 캐시와 진행 중 요청 공유를 적용한다. 기기 저장 실패는 다운로드된 이미지 표시를 막지 않는다.
- 기존 다른 작업의 화면 갱신 변경은 수정하지 않는다. Android 빌드는 실행하지 않는다.

## 캐시와 검증

- SVG 캐시는 24시간 유효하며 최대 64개, 직렬화 문자열 750,000자 이내로 제한한다. URL이 바뀌면 별도 로고로 취급한다. PNG 등은 expo-image의 memory-disk 정책을 사용한다.
- 실제 캐시 모듈을 TypeScript 변환 후 격리 실행했다. 동시 요청 20개의 다운로드 1회 공유, 메모리 재사용, 모듈 재시작 후 저장 캐시 복원, 만료 후 재요청, HTTP 실패 후 재시도, 다크 URL 분리, 손상된 저장소와 저장 실패, 캐시 개수와 크기 제한 검사를 통과했다.
- 모바일 타입 검사 통과. 모바일 린트 오류 없음, 기존 경고 2건. git diff --check 통과.
- iPhone 실기기 로딩 시간과 네이티브 캡처 비교는 미검증이다. 최초 다운로드 시간 단축은 측정하지 않았으며 이번 개선은 반복 요청과 재진입 지연을 줄인다.
- 모바일 AGENTS.md가 참조하는 OWNER-A.md는 현재 저장소에 없다. 현재 기준인 README.md와 웹 원본 TeamLogo를 근거로 범위를 제한했다.
