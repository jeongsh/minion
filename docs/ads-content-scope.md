# 광고 적용 범위

## 2026-10-10: 자동 광고 연결 보완

- AdSense 브라우저에서 사이트 상태는 `준비 중 / 광고 게재 가능 여부 검토 중 / 리뷰가 요청됨`으로 확인했다. `ads.txt 승인됨`은 사이트 승인과 다르다.
- 열린 광고 설정 미리보기는 자동 광고, 인페이지 배너와 멀티플렉스, 좌우 사이드 레일이 활성화돼 있었다. 앵커와 전면 광고는 비활성이며 제외된 페이지와 영역은 없었다. 이번 점검에서 계정 설정을 저장하거나 변경하지 않았다.
- 운영 홈은 브라우저 실행 후에도 광고 스크립트, 수동 슬롯, 콘텐츠 마커가 없었다. 운영 배포 환경변수 값은 확인하지 않았다.
- `AutoAdContent`는 게시자 ID와 명시적인 콘텐츠 조건으로 자동 광고 코드를 요청한다. 수동 슬롯 ID나 수동 슬롯의 화면 표시 여부에 의존하지 않으며 모바일에서도 동작한다.
- 홈, 게시글 목록과 상세 등 기존 수동 슬롯 페이지는 `AdSlot`을 통해 자동 광고 마커를 제공한다. 수동 슬롯 ID가 없으면 수동 광고 자리를 만들지 않아도 자동 광고를 사용할 수 있다.
- 챔피언 목록은 검색어가 없고 표시할 통계 행이 있을 때, 상세는 선택 범위의 픽 또는 밴 기록이 있을 때 자동 광고를 허용한다. 빈 화면과 검색 결과는 제외한다.
- 전체 광고 활성화는 기존처럼 `NEXT_PUBLIC_ADSENSE_ENABLED=true`가 필요하다. 후속 사용자 요청에 따라 광고 수정만 Git 푸시 및 `dev`에 병합하고, 연결된 Vercel 배포 환경에서 이 변수를 활성화한다. 환경변수 변경 후 재빌드가 필요하며 코드 로딩과 실제 광고 게재 승인은 별개다.
- 일정, 선수 목록, 대회 상세의 레일 전용 경로는 기존 데스크톱 조건을 유지한다. 다른 형식의 모바일 지원 확대는 별도 작업이다.

## 2026-09-20: 전체 광고 임시 중단

`NEXT_PUBLIC_ADSENSE_ENABLED`가 정확히 `true`일 때만 아래 광고 정책이 활성화된다. 기본값은 비활성이다. 운영 환경에서 이 변수를 설정하지 않아도 Git 배포 후 전체 광고가 꺼진다.

비활성 상태에서는 수동 슬롯, `ADVERTISEMENT` 임시 자리, 자동 레일 광고 마커와 광고 스크립트를 생성하지 않는다. 기존 슬롯의 높이도 차지하지 않는다. `NEXT_PUBLIC_ADSENSE_SHOW_PLACEHOLDERS=true`나 기존 게시자·슬롯 ID로 이 차단을 우회할 수 없다. 사이트 확인용 메타 태그와 `ads.txt`는 유지한다.

다시 광고를 표시하려면 배포 환경에서 `NEXT_PUBLIC_ADSENSE_ENABLED=true`로 설정하고 Git 기반 재빌드·배포한다. 클라이언트 환경변수이므로 실행 중 설정만 바꾸어서는 반영되지 않는다. 아래 내용은 재활성화했을 때의 지면 조건이다.

수동 광고 요청은 `AdSlot`의 명시적인 콘텐츠 조건, `lib/ads-policy.ts`의 수동 슬롯 허용 경로, 게시자 ID와 광고 슬롯 설정이 모두 충족될 때만 시작한다. 공통 레이아웃에는 사이트 확인용 메타 태그만 유지한다.

일정(`/schedule`), 선수 목록(`/players`), 대회(`/tournaments/[segment]`)는 수동 슬롯을 추가하지 않는다. `RailAdContent`가 각각 표시할 경기, 선수, 대회 경기가 있을 때 게시자 ID만으로 자동 광고 스크립트를 로드한다. `/tournaments`는 대회 상세로 리다이렉트한다. 이 페이지들은 수동 슬롯 ID가 없어도 자동 레일 광고를 사용할 수 있다.

2026-09-09 성능 개선: 레일 전용 스크립트는 공용 데스크톱 레이아웃 기준인 1200px 이상·hover 가능한 화면에서만 시작한다. [Google의 사이드 레일은 데스크톱 전용](https://support.google.com/adsense/answer/16531757)이며, 모바일에서 보이지 않는 광고 런타임 때문에 전체 문서 탐색이 발생하지 않게 한다. 창을 넓히면 현재 콘텐츠 조건을 다시 확인하고 로드한다. 이미 로드된 광고의 문서 격리 및 수동 슬롯 조건은 유지한다.

당시에는 자동 광고 형식을 좌우 사이드 레일만 켜는 방식으로 운영했다. 2026-10-10 미리보기에서 확인한 형식 설정은 위 최신 기록을 따른다. 코드는 형식을 강제하지 않으며 이 코드 변경은 계정 설정을 수정하지 않는다.

- 홈: 경기 카드 데이터가 있는 경우.
- 경기 상세: 세트 데이터 탭에서 승자가 확인된 세트를 표시하는 경우.
- 선수 상세: 선수의 세트 기록이 있는 경우.
- 팀 홈: 표시할 경기 목록이 있는 경우.
- 커뮤니티 목록: 현재 목록/공지에 블라인드되지 않은 글이 있고 검색 결과 화면이 아닌 경우. 사이드바 인기글 유무로 판단하지 않는다.
- 게시글 상세: 블라인드되지 않고 본문이 있는 경우.
- 승부예측: 기존 광고 활성화 환경변수가 켜져 있고 선택한 기간·대회에 경기가 있는 경우.

로그인, 가입, 계정/설정, 글쓰기/편집, 고객센터, 정책, 검색, 미등록 경로는 광고 스크립트를 불러오지 않는다. 오류 화면은 공용 ErrorState의 차단 마커로 보호한다. 전체 비활성 또는 게시자 ID 누락 시에는 자동 광고도 시작하지 않는다. 수동 슬롯 ID 누락이나 슬롯 숨김은 수동 요청만 막으며, 자동 광고는 별도의 콘텐츠 마커로 판단한다.

Google 스크립트는 실행 후 script 태그를 지워도 해제되지 않는다. 따라서 실제 광고 스크립트가 로드된 문서에서 다른 URL로 이동할 때는 전체 문서 탐색을 사용한다. 프로그램 탐색·뒤로가기·오류·마지막 슬롯 제거도 문서를 다시 로드해 이전 광고 런타임을 종료한다. 광고가 로드되지 않은 문서는 기존 SPA 이동을 유지한다. 이미 발생한 네트워크 요청을 소급 취소하는 기능은 아니다.

새 광고 지면은 경로만 추가하지 말고 현재 화면의 실제 콘텐츠 조건을 함께 제공한다. Google 계정의 Auto ads가 켜져 있으면 허용된 문서 안에서 자동 배치될 수 있으며, 이 변경은 계정 설정 자체를 수정하지 않는다.
