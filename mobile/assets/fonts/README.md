# Fonts

- Pretendard Regular/Medium/Bold/Black: SIL Open Font License 1.1. The bundled TTF files are decompressed from the exact WOFF2 files loaded by `app/globals.css` from https://cdn.jsdelivr.net/gh/orioncactus/pretendard (version 1.309).
- Paperlogy 7Bold: SIL Open Font License 1.1. The bundled TTF is decompressed from the exact WOFF2 file loaded by `app/globals.css` from https://cdn.jsdelivr.net/gh/projectnoonnu/2408-3@1.0/Paperlogy-7Bold.woff2.

The font files are bundled locally so the first Expo Go render does not depend on a network font request and uses the same glyph metrics as the web app.
