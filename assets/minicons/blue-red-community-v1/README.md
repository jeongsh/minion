## 공통 생성 지시

첨부된 파랑·빨강 마스코트의 얼굴, 후드 로브, 벨트, 굵은 외곽선과 광택 있는 2D 스티커 스타일을 엄격히 유지했다. 한 장에는 캐릭터 한 명과 지정 문구 한 번만 사용하고, 128px에서도 의미가 읽히도록 서로 다른 표정·동작·소품으로 구성했다. 최종 편집에서는 전경을 유지하면서 외부 배경을 실제 알파 투명으로 추출했다.
